# SupportPilot — Milestone 1

Modern interactive website: **Login → Dashboard**, SQLite, Flask, AI classification.

**No “How it works” accordion tabs.**

## Theme
- Animated gradient mesh background
- Glass cards, hover lift, press feedback (Flutter-like)
- Count-up stats on dashboard
- White glass UI over dark blue/cyan backdrop

## Run
```bash
cd SupportPilot
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000
